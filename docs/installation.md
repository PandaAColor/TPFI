# Installation

## Stable release

To install TPFI, run this command in your terminal:

```sh
uv add TPFI
```

Or if you prefer to use `pip`:

```sh
pip install TPFI
```

## From source

The source files for TPFI can be downloaded from the [Github repo](https://github.com/PandaAColor/TPFI).

You can either clone the public repository:

```sh
git clone https://github.com/PandaAColor/TPFI
```

Or download the [tarball](https://github.com/PandaAColor/TPFI/tarball/main):

```sh
curl -OJL https://github.com/PandaAColor/TPFI/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd TPFI
uv sync
```
